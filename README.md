# 麦碳算 McdCarbon · 家庭低碳点餐规划师

> 一顿麦当劳的碳排，比你想象的高——把「今天吃什么」变成一次低碳、控预算、看得懂碳排的决策。

基于**麦当劳中国 MCP**（`https://mcp.mcd.cn`）开发的 WorkBuddy Skill：用实时菜单与营养数据做约束求解，给出一家人吃得饱、花得省、碳排低的点餐方案；也能把历史订单蒸馏成家庭饮食月度碳账单。

参赛项目：麦当劳程序员创意开发大赛（1024 程序员节）。非麦当劳官方产品。

## 解决什么问题

- 一家人点麦当劳，经常「每人一个牛肉汉堡套餐」——人均 3.5+ kgCO2e，是一顿家常菜的 3 倍以上；
- 想减碳，但不知道换哪一样；想控预算，又怕吃不饱；
- 麦门消费高频，但没人算过自己家一年在麦当劳「吃」了多少碳。

麦碳算把这三件事变成一次对话：输入人数、预算、忌口，输出一份带碳足迹表格的方案 + 减碳对比；接入历史订单，输出月度碳账单和具体替换建议。

## 功能

### 1. 低碳点餐规划（`plan_meal`）

分层装盘约束求解：

1. **主食层**：每人至少 1 份主食，热量缺口在预算内用主食补齐（杜绝「5 份薯条当饭」式失衡）；
2. **配餐饮料层**：每人最多 2 份配餐，按「饱腹度/碳排」性价比排序；
3. **局部替换**：仅同类互换，朝更低总碳迭代（启发式，非全局最优）。

约束支持：人数、总预算、忌口（不吃牛肉/鸡肉/素食）、人均钠上限、就餐方式（堂食/外带/外送含配送里程）、减碳意愿权重。

输出：餐品表格 + 合计金额/热量/蛋白 + **人均碳足迹与碳评级（A–D）** + 与经典牛肉套餐基准的减碳对比。

### 2. 家庭饮食碳账单（`build_report`）

从 `order-list` 历史订单蒸馏：总碳排、碳强度（kgCO2e/百元）、类别占比、Top 高碳单品、月度趋势、针对性替换建议（如「牛肉汉堡换鸡肉汉堡，每份减约 2.1 kgCO2e」）。

## 目标用户

- **家庭用户**：有娃家庭周末外餐决策，一人食控预算控碳；
- **减碳/ESG 从业者**：需要向客户展示「个人碳账户」玩法与口径的顾问；
- **开发者**：想学习如何把麦当劳 MCP 接入真实约束求解场景的参考实现。

## 快速开始

### 环境要求

Python 3.10+，**零第三方依赖**（纯标准库实现 MCP 客户端）。

### 演示模式（无需 Token）

```bash
git clone https://github.com/<你的用户名>/mcd-carbon-planner.git
cd mcd-carbon-planner
python -m mcd_carbon demo
```

### 接入真实数据

```bash
export MCD_MCP_TOKEN="你的Token"   # open.mcd.cn 控制台申请
python -m mcd_carbon plan < input.json    # input.json 含 meals + constraints
```

WorkBuddy 中作为 Skill 安装：将本项目放入 `~/.workbuddy/skills/mcd-carbon-planner/`，
按 `SKILL.md` 的触发词直接对话使用（如「一家三口吃麦当劳，预算 100，帮我规划减碳方案」）。

### 运行测试

```bash
python tests/test_planner.py     # 7 个用例：碳因子排序/预算/忌口/素食/减碳/报告/评级
```

## 碳足迹口径（重要）

- 餐品因子为**量级估算**：综合 IPCC 排放因子、公开食物 LCA 研究区间中值、连锁快餐供应链一般特征，仅供同一场景横向对比，不构成核算依据；
- 计算包含：食材本体 + 独立包装（0.09 kgCO2e/件）+ 就餐方式附加（堂食/外带/外送含里程）；
- 餐品、价格、供应状态以麦当劳官方实时数据为准。
